# Веха 4 — детали аукциона и ставки

Цель вехи: пользователь открывает аукцион из списка, видит контрактные детали и историю ставок, может перейти по прямой ссылке в режим установки ставки и после успешной mutation получает актуальные данные списка, деталей и ставок.

## Архитектурные границы

- Серверное состояние деталей и ставок остаётся в TanStack Query; MobX не используется для API-данных.
- `entities/auction` содержит контракт, query hooks, ViewModel и отображение данных одной сущности.
- Пользовательское действие установки ставки и его форма размещаются в отдельной feature.
- Состояние режима ставки хранится в URL, поэтому прямые ссылки и обновление страницы воспроизводимы.
- Все внешние данные, URL-параметры и значения формы валидируются Zod; типы выводятся из схем там, где это применимо.

## Условие завершения

Веха завершена, когда аукцион открывается из списка и по прямому URL, корректно отображает детали и историю ставок, позволяет установить допустимую ставку, обрабатывает ошибку валидации и обновляет связанные данные через TanStack Query.
