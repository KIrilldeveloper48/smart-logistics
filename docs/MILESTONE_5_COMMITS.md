# Веха 5 — финальная проверка и передача проекта

Цель вехи: подготовить SPA к сдаче — оставить только критичные автоматические проверки, устранить найденные на финальном аудите проблемы и привести документацию в соответствие с фактической реализацией.

## Последовательность коммитов

| № | Сообщение коммита | Результат | Проверка |
| --- | --- | --- | --- |
| 1 | `test(auction): cover bid form validation` | Добавлены критичные тесты чистой Zod-валидации ставки: обязательность цены, диапазон, направление торгов, фиксированная цена и дробный шаг. | `npm run test` проходит; некорректная ставка не считается валидной. |
| 2 | `test(auction): cover bid mutation cache refresh` | Добавлена минимальная проверка успешной mutation и инвалидирования list/detail/bets; отдельно проверяется отображение 422 у цены. | После успешной ставки связанный cache помечается устаревшим, 422 остаётся в форме. |
| 3 | `fix(quality): resolve final delivery audit findings` | Проведён финальный аудит контрактов, FSD-границ, accessibility и UX-состояний; исправлены только подтверждённые проблемы. | `typecheck`, `lint`, `build` и целевые тесты проходят. |
| 4 | `docs(readme): document delivered application` | README отражает готовое приложение: запуск, MSW, маршруты, основные сценарии, команды проверки и известные ограничения. | Новый разработчик может запустить проект и проверить основные сценарии по README. |
| 5 | `docs(ai): add AI usage disclosure` | Добавлен обязательный `AI_USAGE.md`: вклад AI, решения кандидата, отклонённые предложения, зоны ручной проверки, риски и возможные улучшения. | Документ соответствует пунктам тестового задания и не скрывает принятые компромиссы. |

## Границы вехи

- Не расширяем тестовое покрытие «для процента»: проверяем только критичные правила ставки и обновление cache.
- Все остальные сценарии остаются в `TEST_PLAN.md` как отложенные проверки.
- Финальный аудит не должен менять контракт API или добавлять новый функционал без отдельного решения.

## Условие завершения

Приложение собирается, запускается локально, работает с MSW-моками; README и `AI_USAGE.md` позволяют проверить и оценить выполненное тестовое задание без дополнительного контекста.
